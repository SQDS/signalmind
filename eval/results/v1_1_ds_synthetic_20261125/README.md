SignalMind 使用生产诊断、同父候选、程序门、独立盲看及发布流程。输入范围固定在 T1 检测清单，角色记忆从独立空快照启动。仅在基准中注册解析模拟器的 ECG_RR 开发配置，沿用短核心数值检查和 QRS 保护参数。此配置的校准状态为 `engineering_simulation_only`。[C031 实际修补对比图](C031-repair.png)

两次接口预检共 4 个请求。第一轮读图成功，第二步未按工具契约回传随机码。明确第二步提交要求后，图像读取和工具往返均通过。预检和正式运行共 53 个请求，全部收到服务端用量。按峰时费率估算共 **0.05172 美元**，本轮新增未知费用预留为 0，增量上限为 0.50 美元。平台实际扣款单独核对。[官方计费说明](https://api-docs.deepseek.com/quick_start/pricing/)

## 修正后的离线重放

原始模型回复、回执、工件及当时的执行代码已保留。后续接口接受显式重述的固定算子参数，并核对通道、锚点和实际写入长度；补充具体读取范围说明；识别完全符合契约的 JSON 文本；为通用 Agent 的最后一轮留出提交机会。发生实质差异的工具反馈会改变后续模型决策，不能用离线结果回填原实测。

用原始的 11 个计划或试修调用重新执行后，有两条先前被拒的 C017 提案获得了有效数组，一条来自通用 Agent，一条来自一次性规划。两条对应同一注入点位，核心 MAE 均约 0.00038。C031 的两条通用 Agent 试修即使接受固定参数，仍因读取范围未授权外侧锚点而失败。未知候选 ID、重叠写入和损坏 JSON 均保留原有错误语义。[离线提案核对](proposal-audit.json)

## 本地 Vital 与证据范围

另以两名历史 Vital 开发患者的原生观测做了 6 个本地输入，三组各执行 6 次，均使用脚本回复。在 4 个注入点位上，固定初筛发现 2 处；两处都与受扰后检测出的心搏保护范围重叠。SignalMind 保留了两处，一次性与通用脚本组各修回 2 处。真实波形留在本地。这个结果可以复核检测、心搏保护和未处理原因。[本地工程回归](vital-offline-summary.json)

本次只有一个虚拟记录，且通用组的交付受到协议问题影响。独立患者上的架构增益、修正后通用组的模型表现、跨厂商对照及已校准的安全与覆盖界限均待验证。
