## 显式开发域实跑

相同两名 Vital 开发患者，三通道共 453 个连续块，以 v1.1 本地规则模式完成。逐块比对保存的波形内容哈希、来源 SHA 和探针哈希，两张原生测量表逐字节一致。该运行检查用途域和交付链路，与模型组别的对比需另行冻结配置。

本轮规则模式给冻结的检测候选评估其对应数值操作的适用性。计数为 `eligible` 3，`need_evidence` 11，`preserve_physiology` 17，`unsupported` 4,303。多数触发类型超出当前登记的短核心算子范围，这些计数衡量算子适用性。

用途对照测试包含 4 点在 125 Hz 和 1 kHz 下分别对应 32 ms 和 4 ms、未知单位或设备、不同 ECG 用途、时间断点、缺失锚点，以及已知域内通过真实算子和独立测试回执发布的正例。
