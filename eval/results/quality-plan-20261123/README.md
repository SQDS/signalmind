# 全库质量流程的工程验收

两名 Vital 开发患者的 ECG、PPG、ABP 共 453 个通道记录块、4,545,000 个采样点。在本地规则模式下，4,334 条初筛候选完成冻结和复扫。

对同一真实 ECG 背景的四个位置分别注入强双相、强单向和中等单向尖峰，每处两个采样点。固定提议、测试复查器一律同意时，三组均精确定位 4/4，程序硬门分别放行 4/4、0/4、4/4。各组注入区外的数值改动均为 0。这个对照衡量程序硬门，真实 DS 的前后比较单独报告。

多类型合成初筛涵盖 78 条生成记录。留出组的 39 条记录中，事件精确率为 52.0%，召回率为 78.8%。原生病例的清洗质量尚缺独立干净参照。
