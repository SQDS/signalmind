# 已定位短尖峰的修补对照

同一版 deepseek-flash 通过正常整库入口做诊断、规划和独立复查。比较前后两次的数据清单、患者、分组方式、细察档位、图像和调用预算相同，逐项核验了初筛告警的通道、样本边界和触发原因。各条件使用独立的空经验库和新模型回执。实际交付数组由本地评分器与留存的注入前观测比较。

| Vital 注入形态 | 自动定位 | 旧版修回 | 本版修回 | 核心 MAE，旧版交付 → 本版交付 | 注入区外 ECG 改值 |
|---|---:|---:|---:|---:|---:|
| 强双相 | 4/4 | 1/4 | 4/4 | 0.9973 → 0.0028 | 0 |
| 强单向 | 4/4 | 0/4 | 0/4 | 1.3294 → 1.3294 | 0 |
| 中等单向 | 4/4 | 0/4 | 2/4 | 0.3988 → 0.2007 | 0 |

三种形态分别加到同一名患者同一段 125 Hz ECG 的同四处，每处 2 个采样点。两个样本均实际写入、标记为估计且 MAE 下降才计为修回。这些是用于开发的反例，独立患者上的恢复准确率尚待检验。

强双相的四处中，首轮接受两处，另两处经过一次返工后接受。该运行达到返工上限后仍有 18 项复扫发现待处置，整条运行标为部分完成。中等单向的四处均进入试修，独立复查仍退回两处。强单向的四处均与原生 QRS 保护区重合。原先七处疑似生理心搏的本地重放也再次被边界保护拦住。此次对两名患者的完整原生记录沿用历史结果，只对获授权的三组注入数据重新调用模型。


## 完全合成对照

使用上次完全由公式生成的五个相同输入，包括无注入对照和三通道扰动。各形态和通道单独计分。

| 条件 | 旧版修回 | 本版修回 | 本版注入区外改值点 |
|---|---:|---:|---:|
| ECG 强双相 | 0/4 | 4/4 | 0 |
| ECG 强单向 | 0/4 | 0/4 | 0 |
| ECG 中等单向 | 0/4 | 3/4 | 0 |
| PPG 双相 | 2/4 | 4/4 | 0 |
| ABP 双相 | 2/4 | 4/4 | 1 |

无注入对照的三路数值改写共 0 点，新增停用 0 点。
